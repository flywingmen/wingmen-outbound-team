# Contributing

Thanks for helping make outbound less spammy.

## What helps most

- **New signals** with how to spot them and how fast they decay (`skills/outbound-team/references/signals.md`)
- **Sharper copy rules** from messages that actually got replies (`references/copy.md`)
- **Better weekly reviews**: questions that find the leak faster (`references/pipeline.md`)
- **Fixes to agents** that routed wrong or asked too much

## The three rules a change must keep

1. Nothing sends, launches, approves or saves targeting without a person saying yes to the exact preview.
2. No signal, no message. Never invent a signal, a quote, a number or a result.
3. Every score carries a written reason a stranger could check.

## House style

Short sentences. Plain words. No em dashes. Write like you talk to a busy founder.

## How

Fork, branch, keep each pull request to one idea, and say in the description what it changes in an agent's behaviour. Run `claude plugin validate .` before you open it.
